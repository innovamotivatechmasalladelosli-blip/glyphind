# Glyphind — resultados de la entrega

## Aplicación local-first y sin infraestructura remota
- [x] La aplicación se ejecuta como frontend web sin servidor de aplicación ni base de datos gestionada.
- [x] Los proyectos y cambios del editor se conservan íntegramente en `localStorage` del navegador.
- [x] La experiencia incluye una indicación visible de guardado local y funciona sin depender de una cuenta.

## Panel de proyectos inspirado en la referencia
- [x] El panel principal tiene navegación lateral blanca, jerarquía tipográfica marcada, lista amplia de proyectos y acción «Nuevo» destacada.
- [x] La interfaz está en español y se adapta a escritorio y pantallas reducidas.
- [x] Se muestran proyectos con icono, nombre, tipo, estado y última modificación.
- [x] La búsqueda por nombre y el filtro por tipo permiten localizar proyectos rápidamente.
- [x] Existen estados vacíos y mensajes contextuales cuando no hay proyectos o no hay resultados.

## Creación y gestión
- [x] «Nuevo» permite asignar nombre y elegir Flujo, Pendientes, Equipo, Comunidad u otro tipo disponible.
- [x] Cada proyecto puede abrirse, renombrarse, cambiar de tipo, duplicarse y eliminarse con confirmación.
- [x] La estructura de tipos es extensible mediante un catálogo de metadatos.

## Editor inicial
- [x] Cada proyecto se abre en un editor con lienzo, elementos seleccionables, panel de propiedades y acciones de guardado local.
- [x] El editor incluye nodos de muestra editables y una estructura preparada para incorporar nuevos tipos de diagramas.
- [x] Los cambios del proyecto se guardan de forma explícita y automática en el almacenamiento local.

## Verificación de entrega
- [x] Conectar el repositorio canónico de GitHub cuando el usuario proporcione o autorice la cuenta/repositorio de destino.
